# Character turnarounds — issue #29

Original generated SOLOSRC character designs, provided under the repository MIT
license. Built-in image generation was used; exact prompts are in
`turnaround-prompts.json`. Only the body_a and body_b prompts produced the
accepted character deliverables. The disk prompt there is a rejected experiment;
the delivered prop sheet is drawn in SVG instead. No third-party image is included.

- `turnaround_a.png`: male, front / left side / back / three-quarter.
- `turnaround_b.png`: female, same views and costume family.

Director clarification: A is male; B is female. Both sheets propose a 1.70 m,
approximately seven-head adult anime build, compatible with the shared rig.
Height is a modelling target, not pixel calibration: the generated head ruler
and guide lines are illustrative. Use the front/side/back silhouettes and
normalize the crown/sole span in Blender. Three-quarter is supplementary.

These are raster concept originals, not layered paintings or finished models.
The clothes demonstrate one complete outfit family; hair, jacket, trousers and
shoes must become separate skinned parts during production. Neither image adds
an outfit/hairstyle to the approved creator count. Retain the GDD tint controls.
