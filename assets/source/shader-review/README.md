# Shader review captures

Original SOLOSRC artist-side diagnostic, MIT. Uses project assets and Fable's
shared shaders; no external images. See docs/requests/shader-art-review.md for
commands, renderer, settings, evidence and acceptance limits. Captures are
engine renders. Quads in the close comparison are enlarged for material review;
CameraFraming supplies the separate true-scale check. The script composes a
sample face for inspection only and does not implement runtime CardView.
